# 中国大陆地区登录限制

后台入口：**系统设置 → 安全与认证 → 地区登录限制**。开关默认关闭；修改后点击本区域的「保存设置」，并按现有安全设置完成二次验证。

## 生效范围

- 开启后，登录页先检查客户端网络地址。识别为中国大陆时显示地区限制提示；中国香港、中国澳门、中国台湾单独处理。
- 服务端在签发新登录会话前再次检查，覆盖密码、通行密钥、二次验证、第三方登录及注册后的自动登录。仅隐藏弹窗或直接提交请求不能绕过规则。
- 普通注册和第三方首次登录在消耗邮箱验证码、创建账号、占用邀请码或发放注册权益之前检查地区；前置检查拒绝时不执行这些写入，签发会话时仍保留最终检查。
- 包括管理员在内的所有账号统一受限，提示页不提供管理员专用登录入口。开启后，管理员从中国大陆也无法重新登录；仍有效的管理员会话可以进入后台关闭开关。
- 首页、已登录会话及其正常续期、接口密钥调用不受这条规则影响。没有新增全站或模型调用中间件。
- 开关保存后当前服务实例立即生效；其他实例至多在 5 秒后更新缓存。

提示主文为：

> 考虑到《生成式人工智能服务管理暂行办法》等相关监管要求以及法规要求，本站暂不向中国大陆地区提供服务。

该文案沿用运营方确认的表述；实际技术限制仅针对新登录，并不停止接口密钥调用。

## 地址识别与部署

使用项目已有的可信代理链获取客户端地址。反向代理部署需要正确配置 `server.trusted_proxies`，且代理必须正确覆盖转发头；未受信任的请求不能通过自行提交 `X-Forwarded-For`（转发来源地址头）改变识别结果。

程序内置 DB-IP（地址归属数据库）2026 年 11 月的离线国家与地区数据，支持 IPv4 / IPv6（两种网络地址格式）。查询不上传访客地址。来源、许可证、校验和及更新方法见 [地址库说明](backend/internal/pkg/ipgeo/README.md)。地理归属为估计结果，可能误判，也不能识别代理背后的实际所在地。

开关开启时，非公网地址、无法识别的地址和地址库错误都会暂停所有账号新登录，并显示「暂时无法验证登录地区」及重新检测入口，不会错误地显示为大陆。设置读取失败也暂停所有账号新登录，管理员同样受限；已有会话和接口密钥调用继续按原规则处理。

## 接口

- `GET /api/v1/admin/settings/region-access`：读取 `{ "enabled": false }` 形式的设置。
- `PUT /api/v1/admin/settings/region-access`：更新开关，必须明确提交布尔值 `enabled`（是否启用）；沿用管理员认证、操作审计及二次验证。
- `GET /api/v1/auth/region-access`：登录页预检。正常返回 `{ "allowed": true }` 或 `{ "allowed": false, "reason": "MAINLAND_ACCESS_DENIED" }`；异常返回 503（暂时不可用），原因标识为 `REGION_LOOKUP_UNAVAILABLE`。响应使用项目统一数据封装，禁止缓存。

服务端新登录被拒绝时返回 403（禁止登录），原因标识为 `MAINLAND_ACCESS_DENIED`；无法判断时返回 503。识别失败不会自动关闭开关。
