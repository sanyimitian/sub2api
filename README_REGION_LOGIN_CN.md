# 中国大陆地区访问限制

后台入口：**系统设置 → 安全与认证 → 地区登录限制**。地区限制总开关和「开启全站区域限制」均默认关闭；修改后点击本区域的「保存设置」，并按现有安全设置完成二次验证。

## 两种作用范围

| 地区限制 | 全站区域限制 | 行为 |
| --- | --- | --- |
| 关闭 | 任意 | 不限制地区访问。 |
| 开启 | 关闭（默认） | 仅限制新登录，首页、已登录用户、会话续期及接口密钥调用不受影响。 |
| 开启 | 开启 | 限制全站页面和业务接口，未登录访客、已登录用户及管理员统一受限。 |

识别为中国大陆的地址受限；中国香港、中国澳门、中国台湾单独处理。

登录模式下，服务端在签发新登录会话前再次检查，覆盖密码、通行密钥、二次验证、第三方登录及注册后的自动登录。普通注册和第三方首次登录在消耗邮箱验证码、创建账号、占用邀请码或发放注册权益之前检查地区。隐藏提示或直接提交请求不能绕过规则。仍有效的管理员会话可以进入后台关闭设置。

全站模式通过统一请求入口校验，覆盖首页、静态资源、后台、用户接口、会话刷新、模型网关及其他业务入口，不依据已有令牌或角色放行。管理员已登录也会受限，需要从允许访问的地区关闭设置。仅健康探活 `GET/HEAD /health` 不受限，以免容器反复重启；跨域预检不执行业务操作，实际请求仍需校验。支付等服务端回调同样按来源地址受限。

普通页面请求被拒绝时，服务端直接返回完整提示页面，不依赖站内脚本或图片。已打开的页面在接口返回全站拒绝、切换页面、重新获得焦点或每 15 秒检查时更新为受限提示；检查通过后恢复内容。前端不会把单纯的登录限制当成全站限制，也不会因地区拒绝主动清除已有会话。

首次检查未成功时不显示业务内容；后续轮询遇到断网、限流等传输故障时保留上次判定，避免误卸载正在编辑的页面。服务端明确返回地区拒绝或地区校验故障时仍立即阻止访问；已经显示的拒绝不会因断网而解除，每个业务请求仍受服务端检查。

设置保存后当前服务实例的后续请求立即采用新规则；其他实例至多在 5 秒后更新缓存。已经开始的流式响应或连接不追溯撤回，后续新请求重新校验。

提示标题为「暂不支持当前地区」，主文为：

> 根据《生成式人工智能服务管理暂行办法》监管要求以及相关法律法规要求，本站暂不向中国大陆地区提供服务。

## 新用户默认语言

同一卡片的「所有新用户默认使用语言」可选择中文或英文。此设置独立于地区限制开关，关闭地区限制时也有效。

首次访问、浏览器尚未保存语言偏好的用户使用该默认语言并在本地记住；已有语言偏好不被覆盖，用户仍可自行切换。沿用浏览器级语言偏好，不增加账号语言字段。旧配置默认中文。

## 地址识别与异常处理

使用项目已有的可信代理链获取客户端地址。反向代理部署需要正确配置 `server.trusted_proxies`，且代理必须正确覆盖转发头；未受信任的请求不能通过自行提交 `X-Forwarded-For`（转发来源地址头）改变识别结果。

程序内置 DB-IP（地址归属数据库）2026 年 11 月的离线国家与地区数据，支持 IPv4 / IPv6（两种网络地址格式）。查询不上传访客地址。来源、许可证、校验和及更新方法见 [地址库说明](backend/internal/pkg/ipgeo/README.md)。地理归属为估计结果，可能误判，也不能识别代理背后的实际所在地。

地区限制启用时，非公网地址、无法识别的地址和地址库错误会暂停对应范围的访问，并显示暂时无法验证地区及重新检测入口，不误报中国大陆。

设置读取失败始终暂停新登录。全站入口保留最近一次确认的作用范围：最近确认未启用全站限制时，不把登录限制扩大为全站封禁；最近已启用全站限制或从未读到有效配置时，暂停全站访问。故障不会将已开启的全站限制变成放行。

## 接口

- `GET /api/v1/admin/settings/region-access`：读取 `{ "enabled": false, "site_wide": false, "default_language": "zh" }`。
- `PUT /api/v1/admin/settings/region-access`：更新 `enabled`（地区限制总开关）、`site_wide`（全站限制）和 `default_language`（默认语言，仅支持 `zh` 中文、`en` 英文）。必须明确提交布尔值 `enabled`；旧客户端省略其他字段时保留已保存值。沿用管理员认证、操作审计及二次验证。旧配置没有 `site_wide` 时默认关闭。
- `GET /api/v1/settings/public` 及页面初始注入配置提供默认语言。保存成功刷新当前实例的页面注入缓存；前端启动时重新读取公开设置，避免其他实例的旧注入缓存影响新访客语言。
- `GET /api/v1/auth/region-access`：登录页预检。正常返回 `{ "allowed": true }` 或 `{ "allowed": false, "reason": "MAINLAND_ACCESS_DENIED" }`；异常返回 503（暂时不可用）。
- `GET /api/v1/site/region-access`：全站访问预检。未启用全站限制或地区允许时返回 `{ "allowed": true }`；全站中间件拒绝时直接返回 403 或 503。

拒绝原因 `MAINLAND_ACCESS_DENIED` 表示中国大陆地区受限；`REGION_LOOKUP_UNAVAILABLE` 表示暂时无法校验。全站错误带 `metadata.scope = "site"`（作用范围为全站），前端据此在任意页面显示受限提示。拒绝及预检响应禁止缓存。
