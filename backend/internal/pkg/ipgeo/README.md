# 离线国家与地区识别

此包使用随程序嵌入的 DB-IP IP to Country Lite（免费国家归属数据库）判断网络地址归属，不会把访客地址发送给外部服务。它使用地理归属数据，而非把网络地址分配机构登记的国家直接当成物理位置。

## 行为与限制

`Lookup(address)` 返回两位国家或地区代码。`CN` 表示中国大陆，`HK`、`MO`、`TW` 独立处理。数据库提供的是网络地址估计位置，不是用户国籍，也不能识别代理背后的真实所在地。

无效地址、非公网地址、未覆盖范围及 `ZZ`（未知）记录均返回可用 `errors.Is` 判断的错误，不会自动当成境外放行。数据读取失败也返回错误。具体拦截和本机恢复策略由上层决定。

`Ready()` 可预先验证及加载数据库。首次加载核对压缩文件校验和，限制解压大小为 64 MiB、记录数为 200 万条，校验地址排序与重叠范围；后续查询使用只读二分查找。索引约 17 MiB 的有效数据，实际分配容量会略大，无需每次查询解压。

免费版本的覆盖与精度低于 DB-IP 付费数据，可能存在误判；任何地理库都不保证完全准确。地址分配和位置会变化，因此部署维护时应定期检查并更新快照。程序不会自动下载或替换数据，避免一次外部服务故障改变访问策略。

## 手动更新

1. 从上述官方页面确认最新月份、许可要求以及公布的校验值。
2. 下载当月 `.csv.gz` 文件到此目录的 `data/` 下，核对解压后的官方校验值，并计算压缩文件与解压文件的 SHA-256。
3. 更新 `ipgeo.go` 的嵌入文件名、`DatabaseVersion` 和 `databaseSHA256`，同步更新本文件的日期、大小、记录数及校验和。删除被替换的旧数据文件，避免发布多份快照。
4. 运行 `go test -race ./internal/pkg/ipgeo`，核对中国大陆、港澳台、其他地区、IPv4 与 IPv6 样本。若固定样本归属发生变化，先核实官方记录，再更新样本；不可为了通过测试直接修改预期。
5. 重新构建并部署。数据库和程序版本一起发布，不会在运行时悄悄变化。
