# 模型鉴定

所有登录用户均可在侧栏展开“模型鉴定”并进入“降智测试”。“掺水测试”标记为开发中，当前不运行检测。

## 使用方式

1. 管理员打开“配置检测”，从站内已有分组中选择关联展示分组，再填写接口基础地址、密钥、接口类型、文本模型、检测间隔和单次超时。关联仅决定展示名称，实际请求仍使用填写的地址与密钥，不按站内账号分组选择账号，也不校验密钥实际属于哪个分组。
2. 保存后按间隔由服务器执行；也可以点击“立即检测”。关闭浏览器不会终止已接受的检测。
3. 普通用户与管理员共享查看已配置的检测分组（暂停定时后仍保留历史展示）。用户可自行选择展示哪些分组，偏好按用户编号保存在当前浏览器。
4. 每组以时间倒序显示最近 24 次记录，拖动滑动条、横向滚动或使用键盘均可浏览。点击作品查看生成回复、提示词、推理强度和执行时间。

固定测试题为：`创建一个html,内容是svg绘制一个鹈鹕骑自行车的2D动画`。每次生成一份作品，逐次积累历史；没有结果时显示等待状态，不生成展示用样本。作品仅供人工比较，不提供自动“降智”评分或模型身份保证。

展示名称跟随站内分组重命名；关联分组被删除后，检测配置和历史作品仍保留，名称回退到上次保存配置时的分组名称。重新编辑时需要选择有效分组。停用的站内分组也可关联用于展示。

## 执行与保留

- 检测间隔支持 1–43200 分钟，默认 30 分钟。调度器每分钟扫描一次，到期时间存在一分钟以内的调度粒度。
- 单次超时支持 60–1800 秒，默认 600 秒。一次定时检测结束后再等待配置的间隔；手动检测不改变原有定时计划。
- 每个计划通过数据库执行租约防止重复运行，多实例共用租约；复用已有最多 10 个并发测试任务的运行器。
- 每次领取检测任务时，在同一事务中捕获地址、密钥、接口类型、模型、推理强度和超时；运行中保存的新配置仅用于后续检测，本次继续使用原配置。凭证快照不返回前端。
- 每次通过配置的基础地址与密钥发送正常 HTTP 请求，由目标服务根据密钥执行分组路由、模型映射、限流与计费。调用消耗配置密钥对应的额度，查看结果不会触发调用，也不会使用查看者的密钥。
- 保留每组最近 24 次记录，包括失败记录；新结果写入后裁剪更早记录，不按天数提前清理。已有管理员账号测试保持原有保留规则和私有可见性。
- 共享预览使用隔离的内嵌页面，禁止访问主站身份、外部网络和嵌套页面。非管理员无法读取上游错误详情及失败的部分响应。

## 地址、密钥与接口类型

- 与渠道监控保持一致，基础地址必须为公网 HTTPS，可带路径前缀；拒绝内网地址、地址中的用户名密码、查询参数和片段。连接时再次校验 DNS 解析结果，且禁止重定向转发凭证。
- 密钥复用站点加密器加密落库。地址和解密后的密钥仅从管理员详情接口返回，响应禁止缓存；普通用户列表和结果接口不包含这些字段。
- 编辑时密钥留空保留原值；修改地址时必须重新填写密钥。管理员可点击“显示密钥”查看已保存密钥，密钥不会写入浏览器本地存储。
- 支持 OpenAI Chat Completions（聊天接口）、OpenAI Responses（响应接口）、Anthropic Messages（消息接口）、Gemini（内容生成接口）。前两种支持显式推理强度；后两种使用模型默认强度，选择不支持的组合会明确报错，不会静默忽略。
- 固定题目通过流式生成请求发送，模型名称或别名原样交给目标接口。截断、空响应和上游失败均记为失败；作品包含配置地址或密钥时会隐藏内容，失败日志和结果会脱敏。

## 接口与部署

- 用户只读：`GET /api/v1/model-identification/groups`，`GET /api/v1/model-identification/plans/:id/results`。
- 管理员详情（包含地址和密钥）：`GET /api/v1/admin/model-identification/plans/:id`。
- 管理员配置：`POST /api/v1/admin/model-identification/plans`，`PUT/DELETE /api/v1/admin/model-identification/plans/:id`。
- 管理员运行：`POST /api/v1/admin/model-identification/plans/:id/run`，接受后台任务后返回 202。
- 随常规部署依次应用 `252_model_identification_groups.sql`、`253_model_identification_credentials.sql` 与 `254_model_identification_display_group.sql`，再启动新版后端与前端。第二个迁移将鉴定目标转为独立配置，保留已有鉴定计划名称和历史作品，并暂停尚无地址/密钥的旧计划，等待管理员补齐。第三个迁移增加可选的展示关联，不按名称或编号猜测旧配置的关联；旧配置保留原名称，编辑时由管理员选择站内分组。已有私有账号测试不会公开。
- 初始没有自动启用的分组计划。管理员需要填写真实地址、密钥与模型后保存配置；缺少这些信息时不会猜测或代填。
