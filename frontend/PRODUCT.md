# Product

## Register

brand

## Users

面向中国大陆的开发者与企业团队，帮助他们通过统一接口接入多种主流大模型。

## Product Purpose

codebot.one（codebot API）提供稳定、高速的 AI API 中转服务。访客可以查看模型价格、API 接入文档和开发教程，并快速完成模型集成。网站的成功标准是让有模型接入需求的客户通过中文搜索找到服务，并清楚地了解如何开始使用。

## Brand Personality

专业、可靠、面向开发者。表达直接，优先说明实际能力、接入方式和价格信息。

## Anti-references

避免关键词堆砌、与实际服务不符的比较，以及无法由服务能力支持的承诺。页面文案应服务于开发者选择和接入模型的真实需求。

## Design Principles

- 先说明统一 API 接入能解决什么问题，再说明如何开始。
- 清楚呈现模型、价格、接入文档和开发教程之间的入口。
- 以准确、可验证的信息建立对速度和稳定性的信任。
- 让搜索摘要和页面可见内容表达同一项服务。

## Accessibility & Inclusion

暂无额外要求。保留语义化标题、可读对比度、清晰的链接文本和键盘可用性，并尊重减少动态效果的系统设置。
