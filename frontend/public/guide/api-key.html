如何创建 AI API Key 并安全使用

创建 API Key 后，开发工具和应用才能通过 Codebot API 调用已开通的模型。请按下面步骤完成密钥准备。

打开 API 密钥页面
1

登录并打开 API 密钥

访问 Codebot API 控制台，登录后进入「API 密钥」页面。没有账户时，请按站点当前开放的注册方式完成注册。

2

创建密钥并选择可用分组

  1. 1
    点击「创建密钥」，填写便于识别用途的名称，例如 claude-code 或 dev-project。
  2. 2
    按控制台说明选择分组。可调用的模型取决于当前账户权限和分组支持范围。
  3. 3
    创建后复制 API Key，并保存在密码管理器或服务端密钥配置中。
!

请勿公开 API Key。不要把完整密钥提交到代码仓库、前端代码、截图或公开聊天中。怀疑泄露时，请在控制台停用旧密钥并创建新密钥。

创建后查看用量

保存密钥后，可以通过站内的用量查询入口查看使用情况。下图沿用完整指南中的历史版本示意，实际界面以当前站点为准。

管理 API 密钥 查询密钥用量
3

在客户端中填写接口信息

Codebot API 为不同客户端提供统一接入地址。OpenAI 兼容客户端通常使用 https://codebot.one/v1；Claude Code 使用 https://codebot.one。请根据客户端类型和官方配置说明填写接口地址及 API Key。

模型名称应以 Codebot API 控制台中当前可用的名称为准，不要直接照抄其他服务商的模型列表。

4
