Claude Code 接入 Codebot API

通过统一接口将 Claude Code 连接到 Codebot API。你可以用 CC Switch 管理配置，也可以直接设置环境变量。

先创建 API Key使用 CC Switch 配置
1

安装 Claude Code

按 Claude Code 官方文档安装所需运行环境和客户端。Windows 用户可使用 PowerShell；macOS 与 Linux 用户可使用终端。

npm install -g @anthropic-ai/claude-code
2

使用环境变量配置接口

将接口地址设置为 Codebot API 站点根地址，并把占位内容替换成你创建的 API Key。

Windows PowerShell

在 PowerShell 中运行以下命令，将接口地址与密钥保存为用户环境变量：

[Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://codebot.one", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "你的API-Key", "User")

macOS 或 Linux

将下面内容加入 shell 配置文件，例如 zsh 用户的 ~/.zshrc 或 bash 用户的 ~/.bashrc：

export ANTHROPIC_BASE_URL="https://codebot.one"
export ANTHROPIC_AUTH_TOKEN="你的API-Key"
!

不要把真实 API Key 写入公开文件。环境变量配置文件也应限制访问权限；密钥泄露后请立即在控制台停用。

3

重启终端并测试

保存环境变量后，关闭并重新打开终端，让新配置生效。进入项目目录后运行 claude，再选择控制台中当前可用的模型进行测试。

如果请求失败，请检查 API Key 是否有效、账户是否有可用额度，以及所选模型是否受该密钥分组支持。
