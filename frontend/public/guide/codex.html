Codebot API 使用文档

Codex 接入 Codebot API

使用 OpenAI 兼容接口将 Codex 连接到 Codebot API。准备 API Key、设置 Base URL，再选择控制台中可用的模型。

查看 Codex 项目创建 API Key
1

准备 Codex 与 API Key

从 Codex 官方项目获取适合系统的客户端，并在 Codebot API 控制台创建 API Key。密钥创建方式见 API Key 教程。

Codex 官方项目 创建并保存 API Key CC Switch 下载与配置
2

在 CC Switch 中添加 Codebot API

打开 CC Switch 的 Codex 配置，添加一个 OpenAI 兼容服务商，并填写：

配置项填写内容
服务商名称Codebot API
Base URLhttps://codebot.one/v1
API Key在 Codebot API 控制台创建的密钥
模型选择控制台当前可用的模型名称
!

Codebot API 接口地址用于 Codex 或其他支持自定义 OpenAI 兼容地址的客户端。ChatGPT 官方网页和官方客户端不能直接改用第三方 API 地址。

3

启用并验证连接

  1. 1
    保存服务商配置，并在 Codex 页签中启用 Codebot API。
  2. 2
    完全退出并重新打开 Codex，使新配置生效。
  3. 3
    使用控制台当前可用的模型发送一条简短请求，确认连接正常。

遇到错误时，先核对 Base URL 是否为 https://codebot.one/v1，确认没有重复添加 /v1，并检查 API Key、额度和模型权限。

4

管理多个客户端配置

如果还需要在 Claude Code 与 Codex 之间切换，可使用 CC Switch 保存多组服务商配置。
